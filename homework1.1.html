4. Discussion

  

    
    
      
  • Public key generation is easy in the forward direction: Q = kG.
    • 
      
  • Recovering k from Q is the discrete logarithm problem and is difficult in real ECC.
    • 
      
  • Hash functions are different: they compress arbitrary input into a fixed-length digest.
    • 
      
  • Both are built from mathematically hard problems, but they are not the same object.
