Public-Key Cryptography and Elliptic Curve Scalar Multiplication

In Ethereum, the relevant elliptic curve is secp256k1. For this toy exercise, we use a smaller curve to understand the core idea behind public-key cryptography.

Curve: y² = x³ + 7 (mod 17)
Base point: G = (1, 5)
Private key: k = 6

Obiettivo

The goal is to understand how a private key is transformed into a public key through elliptic-curve scalar multiplication. The main idea is that Q = kG is easy to compute but hard to invert.

Metodologia

We use a toy elliptic curve and a small base point. By repeatedly adding the point G to itself, we obtain the sequence G, 2G, 3G, ..., kG. The final point is the public key.

Calcoli

Multiplication Point
G(1, 5)
2G(2, 10)
3G(5, 9)
4G(12, 1)
5G(12, 16)
6G(5, 8)

Risultato finale

Q = 6G = (5, 8)

This is the toy public key. In real systems, the numbers are much larger, but the same principle is used in Ethereum and other blockchain systems.

Conclusione

The important idea is that elliptic-curve scalar multiplication is a one-way operation with respect to modern computational assumptions. It allows a private key to generate a public key without exposing the secret scalar itself.
