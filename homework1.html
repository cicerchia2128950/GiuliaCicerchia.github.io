HMWK 1.1 — Example App: Public-Key Cryptography

In Ethereum, the relevant elliptic curve is secp256k1. For this toy exercise, we use a small curve to understand the basic mechanism behind elliptic-curve scalar multiplication.

Curve: y² = x³ + 7 (mod 17)
Base point: G = (1, 5)
Private key: k = 6

The goal is to show the core idea: from a private scalar k we compute a public key Q = kG. This operation is easy to compute in one direction but very difficult to invert in practice. This is the foundation behind public-key cryptography.

1) The toy curve

We are working modulo 17, so all operations are computed in the finite field F₁₇. The equation is:

y² = x³ + 7 (mod 17)

The valid points on the curve are:

O, (1,5), (1,12), (2,7), (2,10), (3,0), (5,8), (5,9), (6,6), (6,11), (8,3), (8,14), (10,2), (10,15), (12,1), (12,16), (15,4), (15,13)

2) Point addition

The key operation is point addition. For two points P and Q, the slope λ is defined as:

If P ≠ Q: λ = (y₂ - y₁) / (x₂ - x₁) mod 17
If P = Q: λ = (3x₁² + a) / (2y₁) mod 17

For this toy curve, a = 0. Then:

x₃ = λ² - x₁ - x₂ (mod 17)
y₃ = λ(x₁ - x₃) - y₁ (mod 17)

3) Computing the multiples of G

We start from the base point G = (1,5) and compute:

Multiplication Point
G(1, 5)
2G(2, 10)
3G(5, 9)
4G(12, 1)
5G(12, 16)
6G(5, 8)

4) Final result

Q = 6G = (5, 8)

This is the toy public key. In a real cryptographic system, the private key is much larger (for Ethereum, 256-bit), and the public key is derived in the same way, just with much larger values and a more complex mathematical setting.

5) Interpretation

The important idea is this: the private key is a scalar k, and the public key is the point obtained by repeated elliptic-curve addition. The operation is deterministic, easy to compute in one direction, and very hard to reverse.

In Ethereum, the actual curve is secp256k1, and the same principle is used for generating wallet public keys and digital signatures.

6) Statistical exploration

If we repeat this experiment with different values of k and different valid base points, we can explore the distribution of the x and y coordinates, their frequency, and whether they appear to behave "uniformly". In cryptography, these distributions are important because they tell us whether the output of the function looks random and unpredictable.

However, elliptic-curve scalar multiplication is not a hash function. It is a public-key operation based on a hard mathematical problem, the Elliptic Curve Discrete Logarithm Problem. This is different from a cryptographic hash function, which maps arbitrary data to fixed-length outputs and is designed for integrity and hashing, not for key pair generation.
